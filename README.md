# AVENTA

Comunidad de ofertas para México: publicar, votar y descubrir promociones con moderación y reputación.

- **Web:** [aventaofertas.com](https://www.aventaofertas.com)
- **Repo público:** código de la app Next.js; lee [docs/SECURITY/PUBLIC_REPOSITORY.md](docs/SECURITY/PUBLIC_REPOSITORY.md) antes de contribuir.

## Desarrollo local

```bash
npm install
cp .env.example .env.local   # rellena con tus credenciales de dev/staging
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Tests

```bash
npm test
```

## Despliegue

El despliegue de producción está en Vercel; las variables de entorno no van en este repositorio.
