# Trust Model

**Evidence:** E1

## ¿Qué necesita saber el usuario antes de confiar?

### Crítico (casi siempre)

| Info | Por qué |
|---|---|
| Precio (y moneda) | Decisión central |
| Tienda / merchant | Riesgo y envío |
| Link verificable | Evidencia |
| Qué producto exacto (modelo/condición) | Match a intención |
| Cuándo se capturó / frescura | Caducidad |

### Importante según ticket

| Info | Por qué |
|---|---|
| Disponibilidad / stock hint | Evita click vacío |
| Reputación del hunter | Proxy de calidad |
| Votos / “útil” en la respuesta | Señal social |
| Comparación vs precio conocido | “¿está barato?” |
| Envío / MSI / restricciones | Constraints del request |

### Ruido potencial

| Info | Riesgo |
|---|---|
| Badges cosméticos sin historial | Falsa confianza |
| Pared de texto de opinión | Carga cognitiva |
| Múltiples links casi iguales | Fatiga |
| Scores opacos de “IA match %” | Teatro de precisión |

## Principio

Confianza = **evidencia verificable + frescura + claridad de constraints**, no score mágico.
