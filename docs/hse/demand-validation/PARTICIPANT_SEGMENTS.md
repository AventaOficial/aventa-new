# Participant Segments — muestra exploratoria

**Objetivo:** patrones cualitativos, **no** representatividad estadística.  
**N sugerido inicial:** 8–15 entrevistas · 5–10 concierge (pueden solaparse).

## Segmentos mínimos

| ID | Segmento | Por qué incluirlo | Señal a escuchar |
|---|---|---|---|
| S1 | Compradores frecuentes tecnología | Ticket + constraints típicos | Q1, Q11 |
| S2 | Compradores ropa/moda | Variantes, talla, estilo | Constraints distintos |
| S3 | Compradores hogar / electrodomésticos | Precio + envío + marca | Esfuerzo alto |
| S4 | Cazadores de ofertas | Ya viven el job discovery | ¿Delegan o cazan solos? |
| S5 | Compradores ocasionales | Menos expertise | ¿Piden ayuda? |
| S6 | Comparadores de precio | Multi-sitio | Esfuerzo Q3 |
| S7 | Compra impulsiva | Contraste | ¿Existe job B? |
| S8 | Usan comunidades para recomendaciones | WA/FB/PD/foros | Q4–Q5 |

## Reclutamiento (investigación aislada)

- No modificar producto AVENTA.  
- Canales: contactos personales, comunidades con permiso, lista de waitlist si existe **fuera** de UI prod.  
- Formulario de screening (Typeform/Notion — **herramienta de research**, no feature):  
  - última compra online &lt; 90 días  
  - categoría aproximada  
  - ¿comparaste precios? sí/no  
  - consentimiento

## Cuotas blandas (orientativas)

Evitar solo amigos tech. Intentar ≥2 no-tech, ≥2 que usen comunidades, ≥1 cazador, ≥1 impulsivo.

## Exclusiones

- Empleados/core team AVENTA como únicos participantes.  
- Personas reclutadas con pitch “prueba nuestra IA”.
