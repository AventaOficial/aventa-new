# Metrics — E4 (definición; sin valores inventados)

**Estado:** todos los contadores de campo = **n/a hasta fieldwork**.

## Demand

| Métrica | Definición |
|---|---|
| N intents expresados | Personas que articulan qué buscan en entrevista o concierge |
| % con restricciones concretas | ≥1 constraint en episodio |
| % reporta dificultad de búsqueda | Dificultad espontánea o a pregunta E |

## Search effort

| Métrica | Definición |
|---|---|
| Tiempo reportado | Autoreporte del episodio |
| # sitios consultados | Autoreporte |
| # búsquedas / rounds | Si se puede estimar |
| Intensidad de comparación | Ninguna / poca / mucha (código cualitativo) |

## Help seeking

| Métrica | Definición |
|---|---|
| % pide ayuda | En episodio concreto |
| Canal | WA, FB, familia, PD, foro, otro |
| A quién | Persona vs comunidad |

## Concierge outcome

| Métrica | Definición |
|---|---|
| Tiempo respuesta operador | Minutos |
| Opciones encontradas / entregadas | Conteos |
| Relevantes según participante | Las que abriría o utilidad ≥3 |
| Descartes operador | Conteo |
| Intención de click | Dice que abriría **o** abre |
| Intención de compra | Dice que compraría / intenta |
| Satisfacción | Utilidad 0–4 |

## Behavioral ladder (no colapsar)

| Nivel | Señal | Más débil → más fuerte |
|---|---|---|
| L1 | Dice que le gusta | Verbal |
| L2 | Dice que lo usaría | Aspiracional |
| L3 | Lo utiliza (en test) | Conductual ligera |
| L4 | Hace click / abre | Conductual |
| L5 | Considera comprar | Conductual + intent |
| L6 | Compra / intenta comprar | Más fuerte |

**Regla:** L1/L2 solos **no** justifican STRONG SIGNAL.

## Anti-métricas

No optimizar: “gustó la idea”, NPS hipotético, likes al pitch de IA.
