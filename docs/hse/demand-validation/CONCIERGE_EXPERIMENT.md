# Concierge Experiment — manual (sin software de producto)

**Principio:** Si el servicio **manual** no genera valor, la tecnología probablemente no arreglará el problema.

**Aislamiento:** Typeform/WhatsApp/email/Notion — **no** rutas AVENTA nuevas, no APIs, no UI prod.

---

## Flujo

```
PERSONA
  → expresa qué quiere (intención + constraints)
  → OPERADOR busca manualmente
  → selecciona 0–5 opciones (honestas, no solo perfectas)
  → entrega resultados
  → PERSONA evalúa / actúa
  → OPERADOR registra proceso + outcome
```

## Brief al participante

> Voy a buscar opciones a mano según lo que me digas. Puede que no encuentre nada bueno. Luego te las muestro y me dices qué harías. No es un producto de AVENTA; es una prueba de investigación.

## Captura de intención (operador)

- Producto / categoría  
- Constraints (precio máx, tienda, condición, envío, ubicación, fecha)  
- Urgencia (ahora / días / flexible)  
- Ya buscó? dónde? qué encontró?

## Protocolo de búsqueda del operador

1. Anotar hora de inicio.  
2. Revisar primero si hay match razonable en AVENTA (solo observación; no modificar).  
3. Buscar en fuentes que el usuario ya usa o típicas (Google, Shopping, ML, Amazon, PD, tiendas).  
4. Registrar cada fuente y descartes.  
5. Entregar **2–5** opciones **o** cero con explicación honesta.  
6. No over-optimize: incluir casos agotados/ambiguos si ocurrieron en el camino (como nota de proceso), pero al participante entregar candidatos actuales si existen.  
7. Anotar hora de entrega.

## Entrega al participante

Para cada opción: nombre, precio, tienda, link, fecha/hora capturada, notas (envío, condición).

Preguntas post-entrega (comportamiento + percepción):

1. ¿Cuál abrirías primero? *(observa si abre)*  
2. En escala 0–4, ¿qué tan útil fue este paquete?  
3. ¿Qué te faltó para confiar?  
4. ¿Comprarías alguna / guardarías / ignorarías?  
5. ¿Preferirías haber seguido buscando solo?

## Qué registrar siempre (Parte 7)

- Tiempo total operador  
- # fuentes revisadas  
- # opciones descartadas + por qué  
- # entregadas  
- ¿Alguna ya en AVENTA?  
- ¿Participante consideró útil? (0–4)  
- Clicks/aperturas observadas (si remoto: auto-reporte inmediato)  
- Cero resultados / agotados / precio cambió / irrelevantes  
- Dificultades de búsqueda del operador  

## N objetivo

5–10 concierge antes de reclamar patrón.  
**Estado actual:** 0 ejecutados.

## Criterio de “valor sin tecnología”

Señal positiva (E4): participante **abre/compara** opciones y declara utilidad ≥3 **o** intención concreta de compra/outbound.  
Señal débil: solo “está increíble” sin revisar.  
Señal negativa: utilidad ≤1 o prefiere su método habitual claramente.
