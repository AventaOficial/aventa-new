# Falsification Criteria

La misión incluye **intentar demostrar que estamos equivocados**.

## Criterios que pueden tumbar la hipótesis

| ID | Criterio | Cómo se vería en campo |
|---|---|---|
| F1 | No hay problema importante | Episodios sin fricción; “siempre encuentro fácil” |
| F2 | Google/Shopping/retailers bastan | Alternativa habitual resuelve; concierge no aporta |
| F3 | Prefieren buscar solos | Code A dominante; rechazan delegación |
| F4 | No quieren esperar | Urgencia total; alertas/caza posterior inútiles |
| F5 | Constraints demasiado complejos / vagos | No articulan B; solo “barato” |
| F6 | Resultados no generan confianza | Piden señales que el concierge no puede dar; no abren |
| F7 | Gustó verbal, cero acción | L1/L2 sin L4+ |
| F8 | Solo micro-categoría | N útil concentrado en nicho irrelevante al negocio |
| F9 | Help seeking ya cubierto por grupos | WA/FB suficientes; sin dolor de estructura |
| F10 | Concierge manual sin valor | Utilidad ≤1 o “hubiera preferido Google” de forma consistente |

## Regla de decisión

- ≥2 criterios F fuertes y consistentes en N≥8 → sesgar a **NO GO** o **WEAK SIGNAL**.  
- Solo opiniones negativas aisladas → no tumbar aún.  
- Solo opiniones positivas sin conducta → **no** STRONG SIGNAL (F7).
