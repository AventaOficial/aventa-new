# Search vs Help — clasificación

Para cada participante/episodio, elegir **una** etiqueta dominante sin inducir.

| Code | Significado |
|---|---|
| **A** | Buscar por sí mismo |
| **B** | Pedir ayuda (pregunta puntual) |
| **C** | Delegar la búsqueda (que otro traiga opciones) |
| **D** | Combinación |
| **E** | Ninguno / no aplica (p.ej. compra impulsiva sin búsqueda) |

## Guía de coding

- Alertas keyword / “avísame cuando baje” ≈ cerca de **A**+espera, no automáticamente **C**.  
- “Le pregunté a mi hermano qué me conviene” ≈ **B**.  
- “Le pedí a alguien que me buscara las 3 mejores” ≈ **C**.  
- Scroll PD + pregunta en grupo ≈ **D**.
