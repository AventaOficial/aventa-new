# Decision Framework — HSE-05

## Escala

| Label | Significado | Requisito de evidencia |
|---|---|---|
| **NO GO** | Problema no suficientemente importante | E4 muestra F1/F2/F3/F10 de forma consistente |
| **WEAK SIGNAL** | Hay problema pero valor débil | Fricción existe; poca acción / preferencia clara por status quo |
| **PROMISING** | Comportamiento + valor para seguir investigando | E4: constraints + dificultad + (help o valor concierge L4+) en varios segmentos |
| **STRONG SIGNAL** | Justifica experimento de producto | E4 **consistente** + conducta (no solo gusto) + concierge aporta vs alternativa; N cualitativo suficiente |

**Prohibido:** STRONG SIGNAL solo por opiniones positivas o “suena cool”.
